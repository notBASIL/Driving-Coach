# Notes for Claude working on this repo

- **Every push must be recorded in `CHANGELOG.md`, in the same push.** App changes go under their
  version heading (newest first, plain language); docs, cleanup and data-pipeline changes go under
  a "Behind the scenes" line of the current version. The automatic daily road-work and monthly map
  data commits made by GitHub Actions are not logged individually.
- Bump the version label in `driving-coach.html` (`<span class="muted" ...>vX.Y</span>`) for any app
  change; the app's self-update check compares it with the live page.
- Show the user a preview before pushing app changes, unless they say to push.
- Don't commit generated build leftovers (see `.gitignore`); `roads/` is generated by the workflows.
